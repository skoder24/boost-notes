# Documentation

Learning notes are grouped by how they were authored, not by topic or quality. Notes whose initial draft was primarily produced with generative AI are in [AI-generated](ai-generated/README.md). Notes whose initial draft and main substance were primarily written by a person belong in `human-authored/`.

Using AI for brainstorming, feedback, or light editing does not by itself make a note AI-generated. If generative AI substantially drafts or rewrites a note, place it in the AI-generated category and describe that contribution where useful. Keep source links and attribution with adapted material in either category.

## AI-generated notes

- [AI-generated notes](ai-generated/README.md) cover foundational learning plans, project ideas, Git and GitHub, and setup guides.

## Human-authored notes

The `human-authored/` directory is reserved for notes primarily written by a person.
